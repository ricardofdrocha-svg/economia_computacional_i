Linha de comando para verificar, através do terminal, a versão instalada do Python:
    python --version

Instruções da aula:
    Pesquisar e abrir "Anaconda power shell prompt"
    Criar ambiente virtual
        python -m venv projeto1
    Ativar ambiente virtual (sair do base e ir para novo ambiente virtual)
        projeto1\Scripts\activate
    Instalar numpy
        pip install numpy
        "não fazer upgrade na máquina da faculdade"
    Desativar
        deactivate
    Criar ambiente virtual
        conda create -n  projeto2 python=3.14
    Ativar Conda
        conda activate projeto2
    Instalar numpy
        conda install numpy
    Desativar conda
        conda deactivate
    
Comandos no terminal:
    "limpar tela": ctrl l
    "listar pastas e arquivos": ls
    "trocar de diretório": cd
    "voltar um diretório": cd ..
    "criar diretório": mkdir
    "listar pacotes instalados do Conda": conda list
