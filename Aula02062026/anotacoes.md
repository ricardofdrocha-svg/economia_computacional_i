# Notas da aula
O Anaconda oferece um ambiente para que o usuário consiga desenvolver usando Windows.

Para um desenvolvedor, o ideal é utilizar Linux.

Em Markdown, os comentários ficam ocultos, como no exemplo a seguir:
<!-- Comentário oculto -->

Em Markdown: # é um pouco diferente de ##

O nome de um arquivo é apenas um caminho relativo, não o caminho completo.

O Python foi criado para operar em cima de C.

O método write escreve apenas strings. Exemplo: 2+2 grava 2+2, não 4. O write é um método, não uma função!

json: JavaScript Object Notation

O arquivo json é um objeto Java, não Python. Portanto, precisa de um dicionário para ser lido em Python.

.csv é muito utilizado, pois .xls é pesado demais.
